# Logos del tech stack

Logotipos oficiales tomados del proyecto **Devicon** v2.17.0 (https://devicon.dev, licencia MIT),
variante `*-original.svg`, convertidos a PNG de 256 px de alto con `rsvg-convert`:

```bash
rsvg-convert -h 256 --keep-aspect-ratio icons/<nombre>/<nombre>-original.svg -o <nombre>.png
```

Los logotipos son marcas registradas de sus respectivos dueños y se usan solo para
identificar la tecnología en la pantalla de créditos.

El logotipo propio de la app está en `assets/brand/` (SVG fuente) y `assets/logo.png`.
